# Demo grass scatter

`tufts.bin` and `manifest.json` are generated by `npm run bake` from
[`tools/bake-demo.ts`](../../tools/bake-demo.ts) and
[`demo/recipe.ts`](../../demo/recipe.ts). The recipe is deterministic;
the test suite rebakes into memory and compares the bytes.

The binary contains only authored numeric placement data. It has no third-party
textures, models, or source assets.
